IMDB API Endpoints

Movies:
- POST /api/movies - Create a movie
- GET /api/movies - Get all movies
- GET /api/movies/{id} - Get movie by ID
- PUT /api/movies/{id} - Update movie by ID
- DELETE /api/movies/{id} - Delete movie by ID

Actors:
- POST /api/actors - Create an actor
- GET /api/actors - Get all actors
- GET /api/actors/{id} - Get actor by ID
- PUT /api/actors/{id} - Update actor by ID
- DELETE /api/actors/{id} - Delete actor by ID

Producers:
- POST /api/producers - Create a producer
- GET /api/producers - Get all producers
- GET /api/producers/{id} - Get producer by ID
- PUT /api/producers/{id} - Update producer by ID
- DELETE /api/producers/{id} - Delete producer by ID

Genres:
- POST /api/genres - Create a genre
- GET /api/genres - Get all genres
- GET /api/genres/{id} - Get genre by ID
- PUT /api/genres/{id} - Update genre by ID
- DELETE /api/genres/{id} - Delete genre by ID

Reviews (Nested under Movies):
- POST /api/movies/{movieId}/reviews - Create a review for a movie
- GET /api/movies/{movieId}/reviews - Get all reviews for a movie
- GET /api/movies/{movieId}/reviews/{id} - Get review by ID for a movie
- PUT /api/movies/{movieId}/reviews/{id} - Update review by ID for a movie
- DELETE /api/movies/{movieId}/reviews/{id} - Delete review by ID for a movie
