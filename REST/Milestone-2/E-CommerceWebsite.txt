E-Commerce API Endpoint Design

Product Operations

Retrieve Products
GET /products

Retrieve Product Details
GET /products/{productId}


Cart Operations

Add item to cart
POST /cart/items

Delete item from cart
DELETE /cart/items/{itemId}

Retrieve items from cart
GET /cart/items


Order Operations

Place an order
POST /orders
Creates an order using the items present in the cart

Cancel an order
DELETE /orders/{orderId}

Retrieve previous orders
GET /orders

Retrieve orders within a given time range
GET /orders?startDate={startDate}&endDate={endDate}
